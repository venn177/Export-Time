An addon for Godot. When enabled, it will create a version.json file in res:// that will look like this, called version.json:

{"version":"2026.03.12.04:36"}

The time is set when you export a project, and is local to the computer you exported it on. I just wanted a simple way to have my main menu tell me the last time I did an export or 'hard version' of my game. I was going to upload this to the Godot Asset Store, but it was too much work. If somebody else wants to, feel free I guess. I think I put it on the correct license?
